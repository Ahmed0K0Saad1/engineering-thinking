# Unit Specification — 0.0 Baseline Records & Diagnostic Protocol

- **Unit ID:** 0.0
- **Title:** Establish Baseline Records and Diagnostic Protocol
- **Phase:** 0 — Baseline & Learning Setup
- **Workflow status:** COMPLETED
- **Gate outcome:** GATE PASSED — 2026-11-18
- **Version:** 1.0

## Purpose
Prepare a reliable, repeatable, evidence-based process for assessing the learner's current starting point without assuming either zero knowledge or mastery. This unit establishes the records and rules required before any Phase 0 diagnostic is administered.

## Inputs
- Current approved roadmap and prerequisite rules.
- Current status in `09-current-status.md`.
- Phase 0 scope and baseline method in `08-phase-00-baseline.md`.
- Workflow-status and mastery-state definitions.
- Baseline matrix, session-log template, and session-logs directory.
- Learner's existing context and selected project list, treated as unverified until assessed.

## Activities
1. Confirm the Phase 0 scope and exclusions; do not start courses or portfolio expansion.
2. Create/verify the baseline matrix, including core areas and prior-project capability audit.
3. Establish the permanent session-log path and the status-summary relationship.
4. Confirm the distinction between workflow status, mastery state, gate outcome, and next-action classification.
5. Define the short-diagnostic protocol: explain, representative application, error diagnosis, and transfer.
6. Confirm how assistance is disclosed and how evidence is linked.
7. Select the first diagnostic topic: **Problem Understanding & Analytical Thinking**.
8. Verify readiness against the pre-diagnostic checklist below.

## Outputs
- A usable baseline matrix.
- A stable `learning-system/session-logs/` directory and naming convention.
- A clear session-log template and status synchronization rule.
- This approved Unit 0.0 specification.
- A first diagnostic topic recorded in current status, without administering its test.
- A readiness checklist whose verified setup items are checked and whose learner-approval items remain open until explicitly confirmed.

## Assessment of Unit 0.0
This is a setup/protocol unit, not a learner-skills diagnostic. Assessment checks that:
- All required records and templates exist and are internally consistent.
- Workflow and mastery vocabularies are distinct and unambiguous.
- The first diagnostic topic is selected but no diagnostic questions/tasks have been presented before the unit gate.
- The learner has accepted the operating protocol and authorized the first diagnostic.
- The next diagnostic can be started without inventing missing process rules.

## Exit Gate / Completion Conditions
All outputs exist; every readiness item is verified; the learner confirms acceptance of the operating protocol and explicitly approves starting the first diagnostic; and the completion evidence is recorded in a session log. No skill is marked mastered by completing this setup unit.

- [x] No diagnostic task was administered before this setup unit's readiness gate.

## Out of Scope
- Administering the first diagnostic as part of Unit 0.0 setup assessment.
- Teaching or testing Problem Understanding & Analytical Thinking before this unit's exit gate.
- Updating mastery states based on prior claims alone.
- Starting Phase 1 systematic instruction, new courses, or a new portfolio project.

## Handoff
After this gate passes, the first short diagnostic is authorized under Phase 0: Problem Understanding & Analytical Thinking. Keep Phase 1's systematic curriculum formally sequenced after Phase 0; engineering-thinking habits may be used as a continuous approach throughout.
