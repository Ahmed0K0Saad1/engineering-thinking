# Learning System — Operating Guide

## Purpose
This directory contains the approved learning blueprint and operating procedures. It must be understandable to a new AI assistant without access to earlier chat history.

## Target Capability
The learner should progressively become able to frame unfamiliar problems; extract requirements and constraints; understand measurement, geodesy, GIS and remote sensing; use relevant mathematics; design algorithms; build software and data systems; process spatial data; validate scientific and computational correctness; and use AI critically.

## Three Coordinated Strands
1. Engineering judgment: problem framing, requirements, decomposition, trade-offs, risks, verification.
2. Foundations: mathematics, computing, geospatial science, programming.
3. Applied capability: software/data engineering, geospatial engineering, professional domains, later AI.

Engineering Thinking is a continuous strand practiced from orientation through every phase. Phase 0 is the initial baseline/setup gate and precedes systematic Phase 1 instruction; analytical habits may be used lightly during Phase 0 and deepen continuously afterward.

These are not competing curricula. The roadmap and dependency file control the sequence.

## Execution Rule
Only Phase 0 is initially authorized. Complete Unit 0.0 before administering any diagnostic. The first diagnostic topic is Problem Understanding & Analytical Thinking, but no test starts until the Unit 0.0 readiness checklist is complete and the learner explicitly approves.

## Session Protocol
Read AGENTS.md and current status; identify the active unit; inspect relevant prerequisites and sources; agree on one objective; teach and attempt; review evidence; save a detailed session log in session-logs/; update current status only as a concise snapshot with links; state one next action.

## Not the Goal
This is not a course-completion checklist, a guarantee of employment, a demand to master all branches equally, or permission for AI to change the learner's direction.
