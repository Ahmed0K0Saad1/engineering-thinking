# Phase 0 — Baseline & Learning Setup

**Status:** NOT STARTED  
**Purpose:** Determine the real starting point without assuming zero knowledge or mastery.

## Baseline Method
For each topic, gather four forms of evidence:
1. Explain in the learner's own words.
2. Apply to a representative task.
3. Diagnose an error.
4. Transfer to a different context.

Use short, focused diagnostics. Avoid a large mixed exam.

## Mathematics Audit
Topics: arithmetic, negative numbers, fractions, decimals, percentages, ratios, units/conversions, algebra, formula rearrangement, equations, geometry, angles, area/volume, trigonometry, coordinate geometry/distance, introductory vectors/matrices, descriptive statistics/probability, calculus exposure.

Evidence: independent calculations; formula rearrangement; geometry/trig task; coordinate task after prerequisites; unit/error explanation.

## Computing Audit
Topics: CPU/memory/storage/files; OS/process/environment/command line; binary/data representation; logic/algorithm tracing; collections/data structures; search/sort/complexity; networking/DNS/HTTP/client-server.

Evidence: explain a simple program's execution; trace an algorithm; explain paths/environments; compare search methods; explain a basic HTTP request/response.

## Programming Audit
Topics: Python syntax/types; conditions/loops/state; functions; collections; filtering/counting/aggregation/sorting; files; exceptions/debugging; modules/environments; OOP; tests; Git; independent problem solving.

Evidence: explain/modify a short program; solve one small problem without a template; debug a flawed example; write a test/check; disclose AI assistance.

## Geospatial Audit
Topics: surveying, observations, units, field notes; accuracy/precision/error/uncertainty; Earth models/geodesy/datums/reference frames; geographic/projected coordinates; projections; vector/raster/attributes/metadata/topology; GIS operations/cartography; remote sensing principles/resolutions; data quality.

Evidence: explain CRS/datum/projection distinctions; identify units/axis-order risks; interpret a small spatial dataset; explain why software success does not guarantee scientific validity; reason about measurement error.

## Existing Project Audit
For each selected project, check whether the learner can explain architecture, trace one feature end-to-end, modify a small component, debug a failure, run/write tests, identify limitations, and distinguish personal contribution from AI-generated contribution. Repository existence does not prove mastery.

## Baseline Matrix
Use templates/baseline-matrix.md. For every topic record task, result, assistance, misconception, status, and action: Skip for now / Review briefly / Study / Defer. "Skip for now" is not permanent mastery.

## Environment Setup
Confirm repository access/local clone; read AGENTS.md; configure safe Git workflow; create logs; decide artifact locations; maintain one status file; avoid tools without a current purpose.

## Exit Gate
Mathematics, computing, programming, and geospatial baselines recorded; project understanding honestly assessed; priority gaps visible; first execution block selected from evidence; learner understands logging and AI workflow.

## First Authorized Action
Create the baseline matrix and begin with one low-pressure diagnostic topic at a time. Do not start a large new course before establishing the current level.
