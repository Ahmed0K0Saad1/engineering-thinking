# Mastery & Assessment Standard

## Principle
Progress is based on demonstrated capability, not hours, videos, or AI-generated output.

## Workflow Status vs Mastery State
These are separate dimensions and must never be used interchangeably.

**Workflow status** describes where a unit, task, or phase is in the execution process:
| Workflow status | Meaning |
|---|---|
| NOT STARTED | Work has not begun |
| IN PROGRESS | Work is actively underway |
| BLOCKED | Work cannot proceed until a stated dependency or decision is resolved |
| READY FOR REVIEW | Work is prepared and awaiting review/assessment |
| COMPLETED | The defined work or setup activity is complete; this alone does not imply skill mastery |
| DEFERRED | Work is intentionally postponed, with a reason |

**Mastery state** describes the learner's demonstrated capability in a topic:
| Mastery state | Meaning | Evidence |
|---|---|---|
| NOT ASSESSED | No reliable evidence | None |
| FAMILIAR | Recognizes terms and purpose | Identifies concepts |
| EXPLAINED | Explains in own words | Clear explanation |
| APPLIED WITH HELP | Completes with hints/guidance/AI assistance | Attempt and exact assistance record |
| APPLIED INDEPENDENTLY | Solves a new representative task without solution steps | Independent work and checks |
| EVALUATED | Detects errors and compares approaches | Review with evidence |
| DEVELOPED | Builds a reusable solution | Artifact, tests, docs, validation |
| NEEDS REVIEW | Previously learned but now unreliable | Retrieval/application failure |
| DEFERRED | Not needed in current period | Explicit reason |

**Gate outcome** is recorded separately from both dimensions:
- **GATE PASSED** means the unit/phase exit criteria were met with retained evidence.
- A gate outcome does not automatically upgrade every related mastery state.

Do not collapse mastery states into one percentage. A unit may be COMPLETED while related skills remain NOT ASSESSED; a skill may be FAMILIAR while a future unit remains NOT STARTED. A gate may be passed while some non-critical skill gaps remain explicitly deferred.

## Gate Specification
Every unit gate defines:
- What must be explained.
- What must be calculated, implemented, or performed.
- A novel transfer task where appropriate.
- Permitted hint level.
- Critical mistakes.
- Validation method.
- Retained evidence.

## Assessment Rules
1. Use multiple problem types when appropriate.
2. Include at least one unfamiliar variation.
3. Ask why the method works.
4. Include edge cases and failure conditions.
5. Check units, assumptions, types, CRS, and domain meaning where relevant.
6. Distinguish justified reasoning from guessing.
7. Record AI assistance honestly.
8. AI-generated work the learner cannot explain is not independent mastery.

## Progressive Hints
1. Point to the relevant concept.
2. Identify a relationship or subproblem.
3. Outline the next step without completing it.
4. Reveal a full solution only after an attempt or explicit request.

The examiner must not reveal the answer while posing the test.

## Phase Gate
A phase can close when critical prerequisites reach the required level, the exit artifact exists, decisions/limitations can be explained, and validation evidence is recorded. Non-critical gaps may be deferred explicitly.

## Reassessment
Use spaced retrieval and a different application, not merely the same solved exercise.
