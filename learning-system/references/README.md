# Reference Library

A curated starting index, not a requirement to read everything. Before each unit, verify current versions and choose one primary source plus only necessary support.

## Engineering & Systems
- [NASA Systems Engineering Handbook](https://www.nasa.gov/reference/systems-engineering-handbook/) — systems thinking, requirements, lifecycle, verification/validation; apply proportionally.
- [ACM/IEEE CS2023](https://csed.acm.org/) — CS knowledge areas and curriculum reference, not a personal course plan.
- [INCOSE](https://www.incose.org/) — systems engineering professional body and resources.

## Mathematics
- [OpenStax Mathematics](https://openstax.org/subjects/math) — prealgebra through calculus/statistics; select only the needed book.
- [Khan Academy Math](https://www.khanacademy.org/math) — targeted practice and skill repair.
- [Paul's Online Math Notes](https://tutorial.math.lamar.edu/) — supporting algebra/calculus explanations.

## Computing & Programming
- [Python Tutorial](https://docs.python.org/3/tutorial/) — official language tutorial; assumes some programming familiarity.
- [Runestone Academy](https://runestone.academy/) — interactive CS/programming material; select a suitable module.
- [VisuAlgo](https://visualgo.net/en) — visual algorithm/data-structure support, not a replacement for implementation.
- [Pro Git](https://git-scm.com/book/en/v2) — free Git book.
- [MDN HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) — HTTP/web fundamentals.

## GIS, Geodesy & Remote Sensing
- [QGIS Training Manual](https://docs.qgis.org/latest/en/docs/training_manual/) — GIS workflows; match installed version.
- [PROJ](https://proj.org/en/stable/) — CRS and transformations.
- [GDAL](https://gdal.org/en/stable/) — raster/vector formats and processing.
- [GeoPandas User Guide](https://geopandas.org/en/stable/docs/user_guide.html) — vector processing in Python.
- [Shapely](https://shapely.readthedocs.io/en/stable/) — geometry models/operations; understand planar geometry and CRS implications.
- [USGS Landsat Missions](https://www.usgs.gov/landsat-missions) — satellite mission/data information.
- [NASA Earthdata](https://www.earthdata.nasa.gov/) — Earth observation data and resources.

## Databases & Software Engineering
- [PostgreSQL Documentation](https://www.postgresql.org/docs/) — SQL/database concepts; use version-specific docs.
- [PostGIS Documentation](https://postgis.net/documentation/) — spatial SQL, geometry/geography, indexes.
- [FastAPI](https://fastapi.tiangolo.com/) — Python API development; continue only if selected for a current task.
- [Docker Get Started](https://docs.docker.com/get-started/) — containers and Compose.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — common application risks, not a complete security program.

## Surveying & Hydrography
- [NOAA Hydrographic Surveying](https://oceanservice.noaa.gov/navigation/hydro/) — hydrographic survey background; complement with project specs.
- [IHO Standards & Specifications](https://iho.int/en/standards-and-specifications) — hydrographic standards; verify current published edition and distinguish drafts.
- [NOAA National Geodetic Survey](https://www.ngs.noaa.gov/) — authoritative U.S. geodetic resources; applicability varies by country.
- [FIG](https://www.fig.net/) — surveying profession and technical resources; verify individual publication status.

## ML & GeoAI
- [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course) — ML fundamentals and evaluation; use after prerequisites.
- [Scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) — classical ML.
- [PyTorch Tutorials](https://pytorch.org/tutorials/) — deep learning implementation.
- [GeoAI review (2022)](https://gi.copernicus.org/articles/11/195/2022/) — research overview, not a software manual or current benchmark.

## Selection Rule
For each unit: one primary source; one practice source if needed; official version docs for implementation; papers only for a defined research question. Record exact title, version/date, relevant sections, and limitations. This index is not a reading checklist.
